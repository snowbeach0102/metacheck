[1단계 - 기초 개념]
- 핵심 정의, 특징, 원리 확인
- 하나의 개념만 사용
- 직접적인 질문 형태 (옳은 것 · 옳지 않은 것 고르기 포함)
- 별도의 복잡한 추론이 필요하지 않음

[2단계 - 개념 적용]
- 실제 사례, 상황, 코드, 데이터 제시
- 학습한 개념을 상황에 적용해 결과를 구하거나 판단
- 비슷한 개념이나 조건을 사례 안에서 구분
- 1~2단계의 추론 필요

[3단계 - 심화·응용]
- 여러 개념을 연결하여 판단
- 복합적인 조건이나 예외 상황 포함
- 문제 해결, 설계, 원인 분석, 코드 끝까지 추적 등이 필요
- 여러 단계의 추론 필요
- 선택지 간 장단점이나 트레이드오프는 해당할 때 고려

[판단 원칙]
- '지엽적인 내용' 자체를 3단계로 판단하지 않는다. 내용의 희귀성보다 문제 해결에 필요한 사고 수준을 기준으로 난이도를 결정한다.
- 단순 암기 문제는 내용이 전문적이어도 1단계가 될 수 있다.
- 기본 개념을 다루더라도 여러 개념을 조합해야 한다면 3단계가 될 수 있다.
- 정의 문장 넷 중 틀린 것을 고르는 문제는 사례가 없으면 1단계다.

[판정 순서] 위에서부터 확인하고, 해당하면 멈춘다.
1) 여러 개념을 연결하고 여러 단계의 추론이 필요한가? 예 → 3단계
2) 사례 · 코드 · 데이터에 개념을 적용하는가? 예 → 2단계
3) 정의 · 특징을 확인하는 직접 질문인가? 예 → 1단계
