- 목표: 시험에 나오는 형태로 정확히 구분하고 적용하는지 본다.
- 난이도: [단계 사양]의 판단 기준을 따른다. 역할 때문에 쉽게 · 어렵게 바꾸지 않는다.
- 범위: [출제 범위]의 세부항목 안에서만 낸다. 용어 정의는 그 시험의 것을 따른다.
- 형식: [시험]의 기출 문장체 · 선지 구성. 지문(q)은 1~2문장 (실전 · 심화 사례는 3문장까지).
- 코드 · SQL · 표: 필요하면 지문에 넣지 말고 code 에 줄바꿈을 살려 쓴다. 언어는 C · Java · Python, SQL은 표준 SQL.
- 오답 보기: 비슷한 용어 · 조건을 바꾼 유사 개념, 코드 · 계산은 흔한 추적 실수로 만든다.
- 해설: 정답 근거 + 헷갈리는 보기가 왜 틀렸는지 보기별로.
- 금지: 법령 · 규격 수치를 지어내지 않는다. 사례 · 코드 속 값은 새로 만들어도 된다.
